# 🎓 Smart Rank Estimator

SmartRankEstimator is a web-based application designed to help students estimate their college admission chances based on their academic scores and rank. The system leverages user inputs like exam marks, board scores, and category to generate a predictive rank and provide relevant college suggestions.

---

## 🚀 Features

- 🔐 **User Authentication** (Signup/Login)
- 📊 **Dashboard** to enter academic scores and view predictions
- 🧠 **Rank Estimation Algorithm** for smart predictions
- 🏫 **College Predictor** with filters based on rank and category
- 📄 **Report Generation** of estimated rank and eligible colleges
- 📱 **Responsive Design** for seamless use on mobile and desktop
